SYSTEM OVERVIEW
ISI Terminal v6.0 ek institutional-grade trading journal aur execution discipline platform hai. Yeh system retail traders ko institutional-level structure provide karta hai — jaise hedge funds aur prop desks use karte hain.

Har trade ke pehle mandatory pre-entry analysis hoti hai — HTF/LTF bias confirm hone ke baad hi terminal access milti hai.
DESIGN PHILOSOPHY
System is principle pe design hua hai: "Process over outcome."

Trader ka focus P/L pe nahi, execution quality pe hona chahiye. Agar process sahi hai — results automatically follow karte hain.

Har session mein trader ko apna HTF structure, LTF confirmation, SMC confluence aur psychological state document karna padta hai — tabhi execute kar sakta hai.
HOW IT WORKS
01 Pre-Entry Analysis — Entry Zone Validation, HTF/LTF bias engine, SMC flags, readiness score, SMI (manipulation) tracking
02 Permission Matrix — auto-filled from Pre-Entry, 8-star execution flow, conflict detection
03 Trade Journal — Psychology, violations, scale, slippage, real duration, screenshot
04 AI Review — Gemini/Groq auto post-trade coaching
05 Monitoring — Calendar/List view, Full Report cards, Advanced Metrics, Cost reports, News impact
THIS PAGE — WHAT IT TRACKS
📡 Strategy Discovery — auto-ranked Bias + SMC + Market State combos, which setup actually makes money
📊 Institutional Expectancy Portal — win rate, expectancy, R-multiple by account
🗂 Recent Sessions Recap — last 100 trades, click any card for full deep-dive
📋 Full Report — every trade as its own card: execution, risk, slippage, duration, bias/SMC, violations + cost, psychology + cost, Entry Zone Validation, SMI, pre-entry, screenshot
🧮 Advanced Metrics — R-Multiple, Drawdown, Session performance, Market Regime, MAE/MFE, Slippage Tracker
🩸 Cost of Violation/Psychology — exact ₹ lost to each rule break and each psychology flag
📰 News Impact · 📅 Calendar/List View · 🧾 Order Tracker (live broker orders)
WHY IT WAS BUILT
Most retail traders fail not because they lack strategy — but because they lack discipline infrastructure.

ISI Terminal fills this gap. It forces the trader to slow down, document every decision, and review every outcome — creating a feedback loop that compounds improvement over time.

"Institutional edge is not a strategy. It is a system."
